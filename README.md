# AI Engineer Path

Личный путь в **AI Engineering**: от «что такое LLM» до своего продукта (Study OS).

Материалы короткие, на русском. Ссылки — по желанию, чтобы не закопаться.

## Уровни

| Уровень | Тема | Статус |
|--------|------|--------|
| [Level 0](level-0/) | Знакомство с LLM без боли | ✅ готов |
| Level 1 | Первый API-вызов и промпты в коде | скоро |
| Level 2 | Контекст и primitive RAG | скоро |
| Level 3 | Нормальный RAG + eval | скоро |
| Level 4 | Агенты и tools | скоро |
| Level 5 | Прод: cost, логи, деплой | скоро |

## Как учиться

1. Открой текущий уровень.
2. Прочитай короткую теорию в файлах.
3. Сделай задания (отмечай чекбоксы).
4. Ссылки с пометкой *глубоко* — только если интересно.
5. Не читай всё подряд из больших репозиториев — они пригодятся позже.

## Куда это ведёт

Дальше соберём **Study OS**: second brain → study buddy → code mentor → doc cop → interview coach → cost dashboard.
