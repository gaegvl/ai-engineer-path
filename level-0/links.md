# Ссылки Level 0

Правило: сначала файлы в `level-0/`, потом ссылки.  
Пометки: **must** / **optional** / **later** / **deep** (легко закопаться).

## Must

Пока must = материалы этого уровня. Отдельные статьи не обязательны.

## Optional (коротко, без кроличьих нор)

- [Wikipedia: Large language model](https://en.wikipedia.org/wiki/Large_language_model) — введение
- [OpenAI tokenizer](https://platform.openai.com/tokenizer) — посмотреть токены
- [OpenAI prompt engineering (intro)](https://platform.openai.com/docs/guides/prompt-engineering)
- [Anthropic prompt library](https://docs.anthropic.com/en/resources/prompt-library/library) — примеры формулировок

- Книга Chip Huyen *AI Engineering* (если будет доступ)
