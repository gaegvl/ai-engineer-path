# Словарь Level 0

| Термин | Простыми словами |
|--------|------------------|
| **LLM** | Модель, которая по тексту генерирует текст |
| **Prompt** | Твой запрос / инструкция модели |
| **System prompt** | Скрытые/стартовые правила поведения |
| **Completion / response** | Ответ модели |
| **Token** | Кусочек текста для модели и биллинга |
| **Context / context window** | Всё, что модель «видит» за один запрос; есть лимит |
| **Hallucination** | Уверенный вымысел |
| **API** | Способ вызывать модель из кода |
| **RAG** | Подкладывание документов в контекст (Retrieval-Augmented Generation) |
| **Agent** | Модель + инструменты + шаги к цели |
| **Evaluation / eval** | Системная проверка качества |
| **Latency** | Задержка ответа |
| **Guardrails** | Ограничения безопасности и поведения |
| **AI Engineer** | Инженер, который строит продукты вокруг LLM |
| **Foundation model** | Базовая мощная модель-платформа |

Если встретил новое слово — допиши сюда своей строкой.
