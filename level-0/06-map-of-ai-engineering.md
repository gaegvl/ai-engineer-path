# 06. Карта: чем занимается AI Engineer и что дальше

## Теория (коротко)

**AI Engineer** строит продукты на foundation models:

- чат / ассистенты;
- поиск по документам (**RAG**);
- **agents** (модель + инструменты: поиск, код, API);
- **evaluation** (как понять, что система хорошая);
- стоимость, скорость, безопасность, деплой.

Это ближе к **software engineering + LLM**, чем к training нейросетей с нуля.

### Твой путь в этом репозитории

```
Level 0  понять LLM руками          ← ты здесь
Level 1  вызвать модель из Python
Level 2  подложить свой текст (primitive RAG)
Level 3  нормальный RAG + проверка качества
Level 4  агент с инструментами
Level 5  логи, $ , деплой
   ↓
Study OS (твой продукт из идей 1,2,4,5,8,10)
```

### Куда пригодятся большие репо (потом)

| Ресурс | Когда открывать |
|--------|------------------|
