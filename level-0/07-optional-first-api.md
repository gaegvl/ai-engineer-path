# 07. Опционально: первый вызов API

Можно пройти **после** файлов 01–06.  
Если пока страшно / нет ключа — пропусти и вернись на Level 1.

## Теория (коротко)

В браузере ты уже общался с моделью.  
Через **API** то же самое делает программа:

1. Берёшь API-ключ у провайдера.
2. Отправляешь HTTP-запрос с messages.
3. Читаешь текст ответа и usage (токены).

Это сердце почти любого LLM-приложения.

## Подготовка

1. Выбери провайдера (OpenAI / Anthropic / другой — любой с docs).
2. Создай ключ. **Не коммить ключ в git.**
3. Положи ключ в переменную окружения, например `OPENAI_API_KEY`.
