# 02. Как устроен чат с моделью

## Теория (коротко)

В чате обычно есть:

1. **System prompt** (иногда скрыт) — правила: «ты помощник», «отвечай кратко», «не вреди».
2. **User message** — то, что пишешь ты.
3. **Assistant message** — ответ модели.
4. **История диалога** — предыдущие реплики тоже отправляются снова.

Модель *не помнит тебя* между сессиями сама по себе.  
«Память» в чате = всё, что снова положили в **context** (окно контекста).

Поток:

```
ты пишешь → сервис собирает system + историю + новое сообщение
         → модель генерирует продолжение
         → тебе показывают текст
```

## Задания

- [ ] Начни **новый** чат. Скажи: `Запомни: меня зовут Тест, любимый цвет синий.`  
  Потом: `Как меня зовут?`
- [ ] Открой ещё один **новый** чат (без истории) и спроси то же. Что изменилось?
- [ ] В одном чате попроси: `Отвечай только одним словом.` Затем задай 3 обычных вопроса. Соблюдает ли правило?
- [ ] Запиши в journal: чем «память чата» отличается от настоящей долгой памяти человека.

## Проверка себя

2. Что произойдёт, если история станет очень длинной? (подсказка: context window / лимит)
